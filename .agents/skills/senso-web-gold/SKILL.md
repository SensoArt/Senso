# Senso Web GOLD

## Resultado
Convertir la web de Senso en una expresión reconocible de su identidad y un canal medible de consultas cualificadas, oportunidades y ventas. Combinar criterio curatorial y disciplina comercial; no prometer resultados por rediseñar.

Leer [contexto de Senso](references/senso-context.md) para identidad, invariantes y contexto que debe recuperarse antes de trabajar. Leer únicamente la referencia de ejecución relevante:
- Para propuestas visuales, fotografía, copy y recorridos: [diseño y conversión](references/design-and-conversion.md).
- Para SEO, analítica, cambios, pruebas y publicación: [entrega y medición](references/delivery-and-measurement.md).

## Recuperar el estado
Consultar la página actual y las fuentes accesibles relevantes antes de recomendar. Identificar producción, previews, archivos locales, cambios existentes y decisiones aprobadas. Si hay un archivo vigente identificado, leerlo antes de usar recuerdos sobre su contenido.

Distinguir aprobado, implementado, publicado y verificado. Respetar la decisión más reciente dentro de su alcance. No repetir diagnósticos resueltos ni crear otra versión cuando una candidata existente resuelva el objetivo. No pedir al usuario archivos o verificaciones accesibles mediante las herramientas disponibles.

Identificar público, objetivo comercial, alcance autorizado y evidencia disponible. Resolver decisiones rutinarias con criterio; preguntar solo por información que cambie materialmente el resultado y no pueda recuperarse.

## Elegir el trabajo
- Auditar: aportar hallazgos nuevos, localizados y demostrables.
- Diseñar: recomendar una dirección principal, con resultado visible y razones concretas. Preparar alternativas solo si ayudan a decidir.
- Implementar: ejecutar exclusivamente el cambio autorizado en el entorno acordado.
- Captar: conectar intención de búsqueda, oferta, página y siguiente compromiso.
- Medir: distinguir interacción de consulta recibida, lead válido, reunión y venta.
- Publicar: comprobar la candidata y proceder solo con autorización explícita para producción.

## Límites de autorización
Esta habilidad no concede permiso para modificar la web. Analizar y preparar propuestas es distinto de editar código o textos. Implementar en pruebas es distinto de publicar.

Cuando se solicite una revisión o aplicar criterio sin especificar cambios, entregar primero el diagnóstico y una propuesta concreta. Si el usuario ya autorizó una implementación delimitada, ejecutarla sin volver a pedir la misma autorización.

Antes de publicar, tener lista una versión revisable, las comprobaciones pertinentes y la reversión. Conservar el resto de páginas y componentes. No cambiar como efecto secundario URLs, títulos, SEO, consentimiento, analítica, configuración o servicios.

No enviar consultas de prueba a terceros, crear campañas, contratar herramientas o ampliar acceso sin autorización.

## Priorizar
Valorar impacto comercial, confianza, diferenciación, probabilidad, rapidez, esfuerzo y riesgo. Usar estimaciones cualitativas si no hay datos para puntuar; no fabricar precisión.

Para cada recomendación material, conectar evidencia → consecuencia → acción → validación. Conservar lo que funciona y preferir el cambio más pequeño que resuelva el problema.

## Entregar
Entregar revisiones y propuestas web como páginas HTML con enlaces directos que puedan abrirse en Chrome. Comprobar el enlace antes de entregarlo. Si es un servidor local, indicar su alcance y no presentarlo como un alojamiento público permanente. No usar el visor de documentos como vía principal de revisión web salvo petición del usuario.

Empezar por el resultado o la decisión principal. Explicar lo hecho, su propósito, lo comprobado y los límites. Proporcionar preview navegable cuando esté disponible; no presentar capturas, archivos o código como un despliegue.

Para una auditoría, identificar página y fecha, evidencias, prioridades y propuesta lista para revisar. Para implementación, identificar versión, alcance, pruebas y URL real si existe. Mostrar una imagen del resultado cuando ayude a evaluarlo.

No declarar creada, corregida, publicada, indexada o medida una acción sin evidencia. Ante bloqueo, completar lo independiente, explicar la limitación exacta y ofrecer el siguiente paso viable.
